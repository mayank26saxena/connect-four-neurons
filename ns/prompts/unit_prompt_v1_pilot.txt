A unit is one direction in the MLP activation space of one layer, with a sign (a "pole"); it **fires** when its pole activation exceeds its own 97th percentile on the dev games. Some units may be random directions with no clean meaning; you are not told which.

Goal: find the most accurate, simple description of when `{UNIT}` fires, written twice: in plain English and as a program `fires(b)` (plus optional `level(b)` 0-9) over the Board API in `docs/NEURON_SCIENTIST.md` (read the "Board API" and "final submission" sections first). Tools (all read only the dev games; run from the repository root):

Method: (1) Look at 40+ examples across bands; write 2-3 candidate hypotheses in `ns/work/{UNIT}/notebook.md`. (2) Test each with minimal pairs via `act` before scoring.
