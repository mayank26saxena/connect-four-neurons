# Neuron Scientist workspace

Created by `scripts/30_ns_prepare.py`. See `docs/NEURON_SCIENTIST.md` for the protocol.

- `units.json` - the units to describe (opaque ids, layer, pole sign). Public.
- `stats.json` - per unit: firing threshold and dev maximum. Public.
- `private/` - the unblinding key and judge answer key. **The describing agent must never read this folder.**
- `cache/` - dev activations (regenerated by the prepare step; not committed).
- `work/<unit>/` - the agent's notebook and its dev-metric calls (logged by the tool).
- `descriptions/<unit>.json` - final submissions.
- `judge/` - text-only detection packs; `judge_answers/` - the judge's answers.
- `report.json`, `report.md` - held-out verification (`scripts/32_ns_verify.py run`).
